Setup

Safari + microphone

SpeakQuest v5 analyzes the recording directly in your browser. Audio waveform analysis measures silence and hesitation locally. Local Whisper transcription runs with Transformers.js and downloads a small speech model the first time you use it. The model is then normally cached by the browser.

Free Version

Local speech analysis + local transcription

No OpenAI API key or Render server is required. Audio analysis is local. The browser downloads the speech-recognition model from Hugging Face/jsDelivr when local transcription is first used.

How scoring works
Fluency = speaking rate + pause frequency + speech continuity
Audio = silence %, long pauses and hesitation profile
Transcript = vocabulary, connectors, grammar targets and mission words
Retry = Attempt 2 is compared directly against Attempt 1
Tutor Mode = recurring patterns and weak metrics are saved on this device
